# 앱스 스크립트로 웹앱 만들기 — 고등학교 정보 실습

구글 스프레드시트와 **구글 앱스 스크립트(Google Apps Script)** 로 «휴대폰에서 열리는 나만의 웹앱» 하나를
2~3차시에 만들어 보는 수업 자료입니다. 서버를 빌리지도, 프로그램을 설치하지도 않습니다. 구글 계정만 있으면 됩니다.

문법 암기가 목적이 아니라 **「문제 정의 → 요구사항 → 설계 → 구현 → 테스트 → 배포 → 회고」** 를
한 바퀴 직접 돌아 보는 것이 목적입니다. AI에게 코드를 받아 쓰는 시대에 더 중요해진
**무엇을 만들지 정하는 힘**과 **받은 코드를 판단하는 힘**을 다룹니다.

---

## 파일 구성

| 파일 · 폴더 | 무엇인가 |
|---|---|
| `앱스스크립트-웹앱-학습앱.html` | **학생·교사가 보는 학습 페이지.** 더블클릭하면 열립니다(인터넷 불필요) |
| `앱스스크립트-실습프로젝트/` | 실습 프로젝트 **4종**. 폴더마다 붙여 넣을 파일 5개가 들어 있습니다 |
| `앱스스크립트-실습프로젝트/README.md` | 편집기에 붙여 넣고 배포하는 순서 (교사용) |
| `LICENSE` | 저작권 및 이용 범위 |

실습 프로젝트 4종 — ① 학급 설문(급식 만족도) ② 학급 문고 대출 관리 ③ 동아리 활동 대시보드
④ 나의 학습 계획. ①번이 기준 주제이고 ④번이 가장 쉽습니다.

---

## 3줄 사용법

1. `앱스스크립트-웹앱-학습앱.html` 을 **더블클릭**해서 엽니다. 위쪽에서 실습 주제를 고르면 예시 코드가 그 주제로 바뀝니다.
2. 왼쪽 목차의 **STEP 1 → 13** 을 따라가며 빈칸을 채웁니다. STEP 12에 붙여 넣을 코드 전체가 있습니다.
3. 다 끝나면 오른쪽 위 **⬇ 내 작업** 을 눌러 산출물을 파일로 내려받아 제출합니다.

> ⚠ 이 학습 페이지는 입력 내용을 **자동 저장하지 않습니다.** 탭을 닫으면 사라지므로 꼭 내려받게 해 주세요.
> 서버가 없고, 학생 개인정보를 한 글자도 받지 않습니다.

## 실습 프로젝트를 실제로 돌려 보려면

스프레드시트 → **확장 프로그램 → Apps Script** → 파일 5개를 붙여 넣고 → `setupSheet` 실행 →
**배포 → 새 배포 → 웹 앱**. 자세한 순서와 주의사항은
[`앱스스크립트-실습프로젝트/README.md`](앱스스크립트-실습프로젝트/README.md) 에 있습니다.

`appsscript.json` 은 편집기에서 기본으로 숨겨져 있습니다 —
**⚙ 프로젝트 설정 → "appsscript.json 매니페스트 파일을 편집기에서 표시"** 를 켜야 보입니다.

## 수업에서 다루는 것

- 개발 프로세스 7단계와 **AI에게 맡길 수 있는 구간 / 맡길 수 없는 구간**
- **기술부채와 이해부채** — 바이브 코딩이 남기는 두 가지 빚, 그리고 갚는 방법
- 확인 가능한 문장으로 쓰는 요구사항, 데이터 계획과 데이터 윤리(최소 수집)
- 스프레드시트를 코드로 다루기(`getValues`·`appendRow`·`setValues`)
- 웹앱의 시작점 `doGet`, 파일 3개가 화면 하나로 합쳐지는 과정, 화면 ↔ 서버 통신과 JSON
- 배포와 접근 권한, 테스트 체크리스트, 프롬프트 설계와 AI가 준 코드 고치기
